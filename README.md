# 政企风控平台

基于原生HTML、CSS、JavaScript构建的现代化政企风控管理平台，使用ECharts进行数据可视化。

## 功能特性

### 1. 健康度数据展示
- **总体健康度情况**: 实时显示平台整体健康度评分和趋势变化
- **预警总体情况**: 分类展示产品、项目、业务预警量及环比变动
- **地市风险健康度评估**: 通过广东省地图可视化展示各地市风险健康度排名

### 2. 多维度风险分析
- **业务流程分析**: 客户信息、营销资源、财务管理等业务环节风险监控
- **产品风险分析**: 和教育、物联网、云视讯等产品线风险状况
- **项目风险分析**: ICT项目与非ICT项目的风险结构分析
- **检查事件分析**: 事件趋势、来源分布、状态分布统计

### 3. 数据权限管理
- 支持不同角色使用风险视图进行风险情况管理
- 数据权限分层管理，确保信息安全

## 技术栈

- **前端**: 原生HTML5 + CSS3 + JavaScript (ES6+)
- **图表库**: ECharts 5.4.3
- **样式**: 响应式设计，支持移动端适配
- **数据**: 模拟数据，可轻松替换为真实API

## 快速开始

1. 下载项目文件

```bash

# 或使用Node.js
npx http-server -p 8081

# 然后在浏览器中访问
http://localhost:8081
```

- 平台标题展示

## 设计亮点

1. **原生技术**: 不依赖任何框架，轻量级，加载速度快
2. **响应式设计**: 适配不同屏幕尺寸，支持移动端
3. **现代化UI**: 采用卡片式布局，视觉层次清晰
4. **数据可视化**: 丰富的图表类型，直观展示数据
5. **交互友好**: 支持筛选、钻取、详情查看
6. **性能优化**: 图表按需渲染，内存占用小

## 自定义配置

### 修改数据
在 `js/main.js` 文件中的 `data` 对象中修改相应的数据：

```javascript
const data = {
    // 修改健康度趋势数据
    healthTrendData: [...],
    
    // 修改业务数据
    businessData: [...],
    
    // 修改地图数据
    mapData: [...],
    
    // 其他数据...
};
```

### 修改样式
在 `styles/main.css` 文件中修改相应的样式：

```css
/* 修改主题色 */
:root {
    --primary-color: #409eff;
    --success-color: #67c23a;
    --warning-color: #e6a23c;
    --danger-color: #f56c6c;
}
```

### 添加新图表
在 `js/main.js` 文件中添加新的图表初始化函数：

```javascript
function initNewChart() {
    const chartDom = document.getElementById('newChart');
    if (!chartDom) return;
    
    const chart = echarts.init(chartDom);
    const option = {
        // ECharts配置
    };
    chart.setOption(option);
    charts.newChart = chart;
}
```
